# Claude skills for Cirro apps (drafts)

Skills that help an app developer, or Claude working for one, put an app on Cirro. They
are drafts: each will be rewritten once the CytoWeave and Proteoscope integrations show
what they need. Copy a folder into `.claude/skills/` in your app's repository to use it.

| Skill | For |
|---|---|
| `cirro-app-integrate` | Adding a Cirro mode to an existing web app |
| `cirro-app-review` | Checking an app against the contract before it is submitted |
| `cirro-app-publish` | Packing and releasing a version |
